# Живой бункер — проект Godot

Откройте `project.godot` в Godot **4.7.2 .NET**. Нужен .NET SDK 10. Для запуска нажмите **F6** в сцене `scenes/Main.tscn` или **F5** для проекта.

Первый экран показывает панораму, поверхность и первый подземный этаж по [`Планировке первого экрана по эскизу`](../Планировка первого экрана по эскизу.md). На сцене есть входная группа, лифт, лестница, вход, руины, КПП, ёж, флаг, коридор, дверь маленькой комнаты и завал. Помещения и постройки получили боковые грани, видимую толщину и пол, уходящий вглубь. [Кадр из Godot](../art/concepts/godot-first-screen-depth.png) показывает одну из ранних визуальных итераций. Нажатие на объект выводит его назначение внизу экрана.

Управление: **WASD** или стрелки — движение камеры, **колесо** — масштаб, **G** — сетка, **Home** — общий вид. Правая панель проводит через цели У1–У13: состояние героя и потребности, расписание, мастерскую, ремонт и улучшение оружия, экипировку и отправку к ремонтному складу. Результат каждого из этих шагов подтверждается вручную; У14–У16 переходят автоматически. 1 игровой час длится 1 реальную минуту, пауза останавливает время, работы, поход и бой. Состояние автоматически сохраняется в `user://prologue-opening.json`; кнопки позволяют сохранить и загрузить его вручную.

Это **полный серый маршрут пролога У1–У16** по [контракту систем](../Этапы/03-SYSTEMS/Контракты%20систем%20демо-пролога.md). Герой уходит вправо; найденные детали, паёк, вода и препарат остаются при нём. Затем идут два автоматических боя: 15 защитников против 50 рейдеров на поверхности, 20 других защитников против выживших рейдеров в коридоре. Боевой экран приближает место боя и показывает здоровье, число бойцов, мощь и иконки пяти полезных и пяти опасных реакций. Нажатие влияет на текущую схватку; пропуск иконки нейтрален. После прорыва рейдеры грабят бункер, уводят жителей, взрывают реактор; Света пропадает, герой возвращается со своим оружием, курткой и грузом. Бункер показан повреждённым.

Это проверка **связности маршрута**, а не готовый вертикальный срез. График пока задаётся учебным шаблоном; полноценный редактор 24 часов, перемещение по комнатам, общий инвентарь, анимации бойцов и полноценная постановка финальной сцены ещё нужны. Клавиши для реакций пока не назначены — иконки нажимаются мышью. Длительности и резервы взяты из [баланса пролога](../Этапы/02-GDD/Проверочный%20баланс%20пролога.md). Проверочные допущения: верстак занимает 2 места и даёт +10% качества на уровне 1; оружие имеет базовую мощь 10, стартовый износ 40% и после улучшения базовую мощь 15; куртка добавляет 5 защиты/условной мощности. Числа боя и последствия реакций также кандидаты для проверки с игроками.

Проверка логики без Godot: `dotnet run --project tests/OpeningCheck.csproj` из папки `game`. Она проходит У1–У16 с реакциями и без нажатий, проверяет паузу, сохранение во время работы и боя, одноразовое действие иконок, состав обоих рубежей, грабёж общего склада и сохранность личных вещей героя.

Сборка C#, проверка логики и загрузка сцены в Godot проверены 7 октября 2026 года. Для командного запуска в изолированной среде папка пользовательских данных Godot была направлена во временный каталог; `user://prologue-opening.json` создан. Продолжение заказа после загрузки проверено тестом симуляции.
