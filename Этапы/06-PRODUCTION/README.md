# PRODUCTION — Код + графика + анимации + звук + контент

**Статус:** Основной производственный этап впереди.

## Что делаем

- Расширить подтверждённый срез до согласованного объёма одиночной игры: жители, группы, экономика, стройка, маршруты, бои и прогрессия.
- Производить контент пакетами: у предмета или события должны быть данные, игровое применение и видимый результат.
- Регулярно проверять сборку, сохранения, локализацию и производительность.

- Опора: [план реализации](../../План%20реализации.md) и [правила разработки](../../Правила%20разработки.md).
