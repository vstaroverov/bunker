# BETA — Игроки начинают ломать игру

**Статус:** Будущий этап внешнего тестирования.

## Что делаем

- Дать игру людям вне команды с разными компьютерами и стилями прохождения.
- Собирать версию сборки, шаги воспроизведения, сохранение и проблему понимания игрового действия.
- Отдельно проверять первые 10 минут, первый день, позднюю игру, установку и локализации.

## Результат и переход дальше

- Переход в POLISH: критические сбои исправлены; основные стратегии не ломают экономику и не ведут в тупик.
- Оставшиеся проблемы упорядочены по влиянию на игрока.
