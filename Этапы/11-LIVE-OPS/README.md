# LIVE OPS — Развиваем годами

**Статус:** План поддержки формируется после релиза.

## Что делаем

- Получать сообщения игроков, воспроизводить проблемы, выбирать приоритет и проверять результат обновлений.
- Добавлять маршруты, события, комнаты, технологии и инструменты моддинга с проверкой старых сохранений.
- Крупные новые направления, включая сетевую игру, проводить через концепт, GDD, системы и прототип.

## Результат и переход дальше

- Для каждого обновления публиковать изменения и проверять совместимость сохранений и модов.
- Частоту и состав обновлений определить по реальному использованию игры.
