# Этапы разработки

Каждая папка хранит результаты своего этапа. Порядок соответствует переходам в [плане реализации](../План%20реализации.md).

**Сейчас:** основные решения IDEA зафиксированы; следующий этап — GDD первого игрового цикла. Документы и макеты более поздних этапов служат исходными материалами; их ворота ещё не пройдены. Для перехода дальше проверяем результат по условиям в README соответствующего этапа.
