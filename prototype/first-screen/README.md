# Первый рабочий экран

Откройте [index.html](index.html) двойным щелчком в браузере. Это небольшой интерактивный макет по [эскизу планировки](../../Планировка первого экрана по эскизу.md): он помогает проверить расположение объектов и первые действия до сборки сцены в Godot.

Что можно проверить:

1. Выбрать объект на сцене или в списке справа и увидеть его координаты.
2. Взломать вход, затем отправить героя по лестнице на первый подземный этаж.
3. Открыть карточку маленькой комнаты. Её оснащение описано в карточке, а не нарисовано в коридоре.
4. Запустить ремонт руин, расчистку завала и открыть пример маршрута через КПП.
5. Включить сетку для проверки границы `x = 55`, дверей и разделения этажей.

Демо-работы длятся 5 секунд, чтобы быстро проверить экран. Их длительность, ресурсы, сохранение и персонажи будут правилами игровой симуляции. Координаты объектов находятся в [layout.js](layout.js); отображение и временные действия — в [app.js](app.js). Проверка данных: `node check-layout.js`.

## Как переносить в Godot

1. Сцена показывает фон, поверхность, два разделительных ряда и подземный этаж. Отдельные слои отвечают за фон, конструкцию, двери, персонажей и выделение.
2. Данные объектов читаются из контента. Их идентификаторы и координаты должны оставаться теми же, что в макете, пока расположение проверяется.
3. Клик выбирает объект и открывает его карточку. Карточка отправляет команду симуляции; симуляция меняет состояние входа, дома, завала или героя. Сцена только показывает новое состояние.
4. После проверки масштаба и прохода героя временные формы заменяются арт-ассетами. HTML-макет остаётся отдельным экспериментом и не входит в игру.

Для C#-проекта потребуются редакция Godot .NET и .NET SDK. Их нет среди обнаруженных инструментов этой рабочей среды, поэтому этот макет можно открыть сейчас, а сборку Godot проверить после установки инструментария.
